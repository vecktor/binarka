### Files that matter

- **`app/binarka.css`** is the design: plain CSS keyed on our classes and data attributes, with tokens as CSS custom properties, a dark theme via `prefers-color-scheme`, and the system font stack (no web font). This is the file to port to `src/ui/style.css`.
- **`components/binarka-page.tsx`** renders the target DOM: size radiogroup, `<button>` cells with Ukrainian `aria-label`s, the message area under the board, the buttons, rules in a closed `<details>`, the confirm `<dialog>`, and the inline SVG logo. The logo word «БІНАРКА» is one outlined `<path class="logo-word">` (glyph shapes from Rubik ExtraBold, SIL Open Font License 1.1; no font file ships), so the `<h1>` text is only «Бінарка».
- **`lib/boards.ts`** holds the fixed boards. They match the prompt, and our engine checked the default board and the `/hint` board.
