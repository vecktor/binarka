## 3. New assumption

> **A-61 (2026-10-12), the settings panel's size, place and paint (FR-68, FR-65, FR-117).** The values are the design's (`design/v0/app/binarka.css`, `review-set-14`). **Below 48rem** the panel is the shared bottom sheet: `max-height: 55dvh` with the `60vh` fallback, padding `1.5rem 1rem` plus the bottom safe-area inset, and at 22.5rem and narrower `padding-top: 1rem`. **From 48rem** the dropdown the page already has (width `min(22rem, column)`, 6rem from the top, its right edge on the column's right edge, padding 1rem, all four borders, the panel shadow); the page's cap of the window less 2rem stays (not in the design text; no shot reaches it, as RQ-2 of A-59). **The theme and language options take the size options' segmented paint and metrics** (one design rule for the three controls): `min-height: 2.75rem`, padding `0 0.5rem`, a 2px border, radius `calc(var(--radius-m) - 0.1875rem)`, `--color-text-muted` on `--color-control-bg` (the design's transparent option over the `--surface` card; the page states the card's colour, because the spec asks each option rule for a `var(--color-…)` fill), 0.9375rem, weight 500, line height 1.2, `nowrap`; chosen: a `--color-primary` frame on `--color-primary-soft`, `--color-text`, weight 700, no inset ring. The theme options grow by content (`flex: 1 1 auto`), the language options are equal halves (`flex: 1 1 0`). The page keeps one rule per control (the design's shared selector list is not copied, so block B's tests of `.size-control` stay as they are), each written in the same literal forms as `.size-control button` (`padding: 0 0.5rem`, `border-radius: calc(var(--radius-m) - 0.1875rem)`, …); a stylesheet test keeps the three rules equal in the shared declarations. No gate shot shows it (`settings-focus` focuses «Темна» while «Як у системі» is chosen). Hover, press and the panel's motion are not ported (OQ-5). The settings panel adds no colour token (under OQ-1 A). **ASSUMPTION; ratified by the user's signature.**
