# Requirements amendment draft: setup sheet "select, then «Почати»" (2026-10-09)

Status: UNSIGNED. Waits for the user's signature in chat ("signed, use defaults" takes every default in section 5). Nothing in `docs/requirements.md`, `openspec/`, `design/`, `src/` or `tests/` has been changed by this draft. Revised after an independent read (12 findings, section 9) and after a second read of the sibling draft (section 9, "Second reader (TD read)").

Basis:

- The user's decision in chat on 2026-10-09 at about 22:33 (UTC+5:30), autonomy-log row 114, after testing the page: today a press on a size or level button in the setup sheet starts a puzzle at once and closes the sheet (FR-97(a)), and a size change keeps the earlier level where it applies (FR-92), so size and level cannot be chosen together. The user finds this not intuitive and chose **"Select, then «Почати»"**, done after the NFR-12 slice and before G2.
- The decision, in the user's words (row 114): "size and level presses only mark a choice; one «Почати» makes one puzzle with both; closing without it changes nothing; 4×4 still offers only «Розминка»".
- This draft reads that as follows (the reading is the draft's, the user ratifies it by signing): a press moves `aria-checked`, the sheet stays open, and the press makes no puzzle, takes no seed and asks for no confirmation. «Почати» makes ONE new puzzle with the marked size and level, with one confirmation if the board has player entries (FR-67, FR-90, FR-98). Closing the sheet without «Почати» (Закрити, Escape, light dismiss) discards the marked choice; the next opening shows the size and level of the board shown.
- Autonomy-log row 116: this draft is the «Почати» part of ONE combined amendment with the theme switch and the English version. A sibling draft (`docs/handoff/theme-language-amendment-draft-2026-10-09.md`) holds those parts. Both are signed together in chat. The order is three slices (S, theme, English), then G2. The sibling amends NFR-5 (the page's language rule) and TC-12 (it allows storing the theme and language preferences only).
- Nothing in this file goes beyond that decision except where marked Q (open question, with a default) or ASSUMPTION.
- Kept as signed: the summary button and sheet structure (FR-95, FR-96, row 92), the level names and descriptions (FR-89), the page retry on a run-out (FR-88, A-38 in substance), the 100 attempt bound (FR-84), the summary format (FR-95), the close button (FR-97(e)), the ids rule (A-41).

Ids: checked by grep in `docs/requirements.md` and `docs/requirements-held.md`. Highest in use: FR-99, NFR-17, A-44, TC-14, BC-8. This draft takes **FR-100**, **FR-101** and **A-45 to A-47**. The sibling draft starts at FR-102, NFR-18 and A-48. This draft adds no NFR, TC or BC row. No id is renumbered (BC-7).

Names proposed by this draft (confirm against the design): start button `[data-action="setup-start"]`. Existing hooks stay: `[data-action="setup"]`, `[data-section="setup"]`, `[data-action="setup-close"]`, `[data-control="size"]`, `[data-control="level"]`, `[data-level-reason]`. No new id and no new attribute that needs an id (A-41 unchanged: four ids per mount).

Part 2 of row 114 (wider, taller rules panel on desktop) is a design note, section 7. It is not a requirement.

## 1. Amended rows (existing id, new text)

Words used below, strictly:

- **Board shown:** the board in the page. Its size and level are in the summary (FR-95) and in the board's `aria-label`.
- **Marked choice** (marked size, marked level): the size and level marked in the sheet while it is open and not yet started (FR-100).
- **Pending action:** as in signed FR-67 and the spec («The pending level is dropped when the dialog is cancelled», spec l. 2074): the action waiting for the confirmation dialog. A press of «Почати» on a board with player entries makes the marked pair the pending action (FR-101).
- **Discarded:** the marked choice is dropped without any change. This happens on Закрити, Escape and light dismiss. «Скасувати» or Escape in the dialog **drops the pending action**.

| FR-100 | MVP | Play page | **Marked choice.** While the sheet is open it holds a marked size and a marked level. Each time the sheet opens, they equal the size and level of the board shown. ## 3. Assumptions and notes

New rows:

- **A-45:** this amendment replaces row 92's "a press starts a puzzle at once" (FR-97(a)) and the immediate size and level changes of FR-43, FR-88, FR-90 and FR-92, by the user's decision in chat (row 114). The summary, sheet, descriptions, retry and ids rules of rows 86 to 92 stay. **ASSUMPTION (it follows from the Q6 default): the user's "closing without «Почати» changes nothing" also covers a cancelled confirmation. The pending action is dropped and the sheet does not reopen (FR-98 already says the sheet does not reopen). The human ratifies.**
- **A-46:** the marked choice lives only while the sheet is open. The page needs a way to learn that the sheet closed. It already listens to the `toggle` event of the sheet (spec, «Choosing and closing the sheet»), so it needs no new listener type and no key handler (FR-59). jsdom has no `popover`, so tests drive it with the stubbed `toggle` event (A-44). **ASSUMPTION: the page keeps the marked choice in its own state, not read back from the DOM. This is an implementation note for the spec-writer, not a requirement.**
- **A-47:** `aria-checked` was "the board shown"; now it is "the marked choice while the sheet is open". Tests that read `aria-checked` to learn the board shown must read the summary or the board's `aria-label` instead, or read it with the sheet closed. This is a deliberate change of meaning, not a regression.

Amended notes (existing ids, applied when signed):

- **A-38:** "at most 3 seeds in total for one press" becomes "at most 3 seeds in total for one «Почати», «Нова головоломка» or mount". "Cancelled confirmations, no-ops and unavailable-level presses still take no seed" becomes "Marking presses, cancelled confirmations and unavailable-level presses take no seed; «Почати» is never a no-op (FR-101)". The retry rule itself is unchanged.
- **A-44:** "closing by a choice needs `hidePopover()` (script)" becomes "closing by «Почати» needs `hidePopover()` (script)". A size or level press no longer calls it.

Other notes:

- FR-69 style (`aria-disabled`) stays for the unavailable levels, now by the marked size.
- A-34 (4×4 offers only level 1) is unchanged; only the moment it applies moves from "board shown" to "marked size".
- Escape in the confirmation dialog and in the sheet stays native (FR-59).
