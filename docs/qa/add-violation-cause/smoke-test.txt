## Instruments and their limits

The tester was the parent session (an agent), not a person. It used two instruments:
- the Claude desktop app's browser pane, against the Vite dev server of this worktree (`npx vite --port 5173`; the same `src/`);
- a scratch Playwright script against both the dev server and `vite preview` of `npm run build` on 4173. The script is copied as `docs/qa/add-violation-cause/smoke-sweep.mjs` (as it ran, including two unused lines), and its 4×4 variant as `docs/qa/add-violation-cause/smoke-four.mjs`.

Everything the script read was identical on the built page and the dev server.

The capture boards of `smoke-boards.json` (p2, p6, p8, mount) were mounted through a temporary, untracked page in the worktree root. It set `window.__binarkaCaptureBoard` and then imported `src/main.ts`. The page was deleted after the run.

DevTools' Accessibility pane was not used. Names were read as `aria-label` attributes, which axe and the a11y e2e also check.

VoiceOver was not run. Real screen-reader output is not a gate (A-28).

Ports 4173, 4174, 4176 and 4177 had no listener before and after the preview run.
